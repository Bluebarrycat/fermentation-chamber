# AI_COLLAB

How to work with the assistant on this project:

- When you request code changes, I will return the **exact file(s)** or **sections** to replace.
- After any code change, I will ask whether to update **CHANGELOG.md**.
- If you need a zip, just say so; I will include only the files you need.
- Prefer clear, imperative requests: e.g., “Add a debug flag to main.py and update README.”
- You can say “go” to apply a proposed plan.
